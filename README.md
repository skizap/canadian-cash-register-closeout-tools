# Canadian Cash Register Close-Out Tools

Public collection of fully editable Canadian cash-count templates and French-Canadian employee training material. All workbooks use Canadian dollars (CAD), exclude pennies, and start with a **C$250.00** register float.

## Comment télécharger

Ouvrez le fichier voulu ci-dessus, puis choisissez **Download raw file / Télécharger le fichier brut** dans GitHub. Pour tout récupérer, utilisez **Code → Download ZIP**. Ouvrez les fichiers `.xlsx` dans Excel ou une application compatible avec le recalcul des formules.

Pour un nouveau quart de travail, ouvrez une copie vierge du modèle. Conservez vos résultats quotidiens dans un emplacement privé, pas dans ce dépôt public.

## Pour tester les nouvelles versions

1. Essayez la version **Guidée** si les employés ont besoin de savoir quels billets et quelles pièces déplacer.
2. Essayez **Grands caractères** si la lisibilité et la simplicité de saisie sont prioritaires.
3. Remplissez toutes les quantités, y compris **0** lorsqu’il n’y en a pas. Les nouvelles versions n’affichent pas les mouvements tant que les entrées sont incomplètes ou invalides.
4. Faites un essai supervisé, puis **recomptez physiquement le tiroir après les mouvements**.

Le total final calculé est un total prévu après les mouvements, pas une preuve que les mouvements ont réellement été faits. Ces fichiers comptent le contenu du tiroir et calculent le fonds à laisser; ils ne comparent pas l’argent aux ventes attendues du système de caisse.

### Version guidée : attention aux échanges

Les cibles bleues du gérant indiquent les quantités à laisser. Elles doivent totaliser le fond de caisse attendu. Pour conserver le bon mélange, il peut être nécessaire de **déposer certaines coupures ET d’en prendre d’autres**, même si le montant net est faible ou nul. Suivez les deux colonnes, pas seulement le net. Si le coffre ne contient pas les bonnes coupures, demandez au gérant.

## Important operating notes

- **All spreadsheet cells remain editable.** There is no worksheet or cell protection; avoid overwriting formulas accidentally.
- Quantities are counts of bills or coins, not dollar totals. Use whole numbers, including zero.
- The default float is **C$250.00**; follow your location’s rules before changing it.
- Safe movements depend on authorization and available cash in the safe. Follow store procedures.
- Keep a useful change-making mix for the next shift.
- **This repository is public.** Do not commit completed counts, employee details, actual safe balances, or other confidential business records here.
